# DES-APP-MOVIL1

## Descripción
Proyecto desarrollado en Kotlin como parte de la asignatura **Desarrollo de Aplicaciones Móviles I**.  
El sistema implementa una aplicación de gestión veterinaria que permite registrar, consultar y administrar información de profesionales, mascotas y servicios asociados.

## Funcionalidades principales
- Registro de consultas veterinarias.
- Administración de datos de veterinarios y mascotas.
- Lectura de datos desde archivos CSV.
- Controladores y servicios organizados por paquetes.
- Implementación modular y buenas prácticas de programación.

## Tecnologías utilizadas
- **Lenguaje:** Kotlin  
- **Entorno de desarrollo:** IntelliJ IDEA  
- **Control de versiones:** Git y GitHub  

## Instrucciones para ejecutar el proyecto
1. Clonar el repositorio:

git clone https://github.com/LilyTapia/DES-APP-MOVIL1.git

3. Abrir el proyecto en IntelliJ IDEA.
   
5. Navegar a la ruta:
   
src/cl/duoc/veterinaria/app/Main.kt

7. Ejecutar el archivo `Main.kt` (clic derecho → Run 'MainKt').
